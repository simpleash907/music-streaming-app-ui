Music Streaming App UI/UX
A modern music streaming mobile app designed to provide a personalized, engaging, and user-friendly music experience with easy navigation, music discovery, playlists, and playback features.

Project Overview
This project was created as part of a UI/UX design assignment. The app focuses on personalized recommendations, playlist management, music discovery, and smooth playback interactions.

Key Features
Personalized playlists and recommendations
Music discovery by genre, mood, artists, and songs
Search functionality
Now Playing screen with playback controls
Playlist and album views
User profile and listening statistics
Light and Dark Mode
Download, Shuffle, Like, and Add to Playlist actions
Interactive Figma prototype

Design
The visual design uses pink, purple, and deep violet tones with neutral backgrounds and colorful artwork. Both Light Mode and Dark Mode were designed to maintain visual consistency and accessibility.
